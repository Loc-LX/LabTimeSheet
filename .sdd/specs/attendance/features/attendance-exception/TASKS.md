AE-01 guards existing V3 predicates that pass because V3 already enforces them; its application persistence test is RED. AE-02's `ck_notifications_type` probe is RED before its migration.
- Before changing a production symbol, run GitNexus impact, inspect callers/processes/risk, and resolve `UNKNOWN` with text search. Report HIGH or CRITICAL before proceeding.
- Test Javadoc names the rule and acceptance scenario, observable failure, and hand-derived expected value. Add Javadoc to changed public/protected members in the same implementation step.

- Run focused and affected attendance/reporting integration/web tests after each task. Before review, run full Maven, `npm run test:ui`, `git diff --check`, and applicable disposable E2E journeys; report actual results. Do not weaken assertions or requirement traces.
