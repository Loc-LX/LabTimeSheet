## Verification gates

For each task, run the focused integration test first and the affected module suite after GREEN. Before the part is ready for review, run full `./mvnw test`, the disposable end-to-end suite, `npm run test:ui`, and `git diff --check`; run GitNexus `analyze --index-only` and `detect-changes --scope all` after the final edit. PostgreSQL-specific behavior uses Testcontainers and the `test` profile. No `.env` access or PostgreSQL on port 55432.

Do not claim the part complete while any listed rule lacks a test/disposition or while C-06's migration is separated from P1-02's cancellation code.
